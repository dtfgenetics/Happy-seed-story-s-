## Series rule

A file is official only when it is reconciled into the controlled project system, has a status/version, and passes the applicable story, science, art, classroom, publishing, and publicity checks.

Book 1 remains a controlled work until its manuscript and illustration/proof gates are explicitly locked. Working images in Library are not automatically approved illustrations.

## Release

A book release requires manuscript lock, science QA, art consistency, illustration placement, print dimensions/DPI/bleed checks, proof review, source-file retention, final release export, and tracker/release-ledger entry.
